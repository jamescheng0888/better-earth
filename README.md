Quan(Alex) Zhou - Coded some of the website, revised some of the code. The title for this project is better-earth. This project lets the user input any location in the world and tells the user in detail information such as a fact about the country the location is in, global fire activity(worldwide past 48 hours), local conditions(temperature, humidity, precipitation, and AQI(US scale)), flights nearby(50 mile radius), nearby tropical cyclones (50 mile radius), recent tornado reports (past 48 hours in a 50 mile radius), earthquakes in the region (50 mile radius and a magnitude scale), and stories from that country. By creating a 3-d globe and highlighting locations around the world, the website allows people to visualize the location they researched. Furthermore, the reader's "imagination" is transformed into concrete details such as flights and local conditions that they can see clearly and understand. The website link to run the project can be found at: https://better-earth.onrender.com/ By creating the connection between a location and details about the region, the user can imagine what the location feels like and is like for the people living there.
